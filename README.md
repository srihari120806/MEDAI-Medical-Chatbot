# 🏥 MEDAI – Medical Assistance Program

A Python-based medical assistance program that provides a menu-driven medical bot, first-aid information, and a BMI calculator.

## ✨ Features
- Medical symptom guidance through a menu-driven interface
- First-aid information for common emergency situations
- BMI calculation based on height and weight
- Age and gender inputs used by the medical bot
- Console-based Python application

## 🛠️ Technology
- Python

## ▶️ Run the Project

```bash
python MEDAI.py
```

## 📌 Important Note
This project is an academic/demo application and should not be used as a substitute for diagnosis, treatment, or professional medical advice. Medication information in the original source is hard-coded and should be verified with a qualified healthcare professional.
